# 平台与发布状态

检查日期：2026-11-03。

## macOS

现有实现包含剪贴板采集、加密存储、卡片搜索、复制／粘贴、收藏、缩写、敏感标记过滤和设置。42 项回归检查覆盖字符串规则与面板模型；不覆盖系统授权、CGEvent 投递、真实输入法或外部应用。

### 编译

```sh
cd macos
./test.sh
./build.sh
```

2026-11-03，提交 `bf814f3` 已在 macos-15（arm64）和 macos-15-intel（x86_64）通过 42 项回归检查、编译、签名与架构校验，并生成 ZIP。[查看验证记录](https://github.com/flyingcow-niu/clipkeep/actions/runs/41610002137)。

### 发布前剩余工作

1. **稳定授权**：配置固定的签名身份，正式分发使用 Developer ID 并公证；不要提交证书和私钥。临时签名构建仍可供开发者自行编译。
2. **数据可靠性**：处理 SQLite 写入错误、明确迁移版本，验证磁盘满和密钥不可读场景；实现备份恢复。
3. **剪贴板竞争**：恢复长短语展开前的剪贴板时先比对 changeCount，避免覆盖用户刚复制的新内容。
4. **手动验收**：TextEdit、浏览器、IDE、Office／聊天应用；中文和英文输入法；多屏、全屏、睡眠唤醒、权限撤销后恢复。
5. **性能**：分别测 2,000／10,000 条历史及大量图片，减少主线程全量查询和解密。
6. **发布流程**：版本说明、校验和、签名安装包、更新与回滚说明。暂不自动发布 Release。

## Windows

项目所有者确认此前没有 Windows 源码，并授权从零实现。当前版本为 C# / .NET 10 WPF 原生早期预览，首要目标 Windows 11 x64。

### 已实现

- 托盘和单实例、Ctrl+Shift+V 呼出、横向卡片、搜索与收藏过滤。
- Unicode 文本、HTML/RTF、图片、文件引用的记录和恢复。
- Ctrl+C 复制并收起、Enter 粘贴、纯文本粘贴、可见卡片数字快选。
- DPAPI CurrentUser 加密整个历史快照，原子写入，解密失败不覆盖历史。
- 收藏保护、保留期限、条数和容量限制、应用进程排除、敏感格式过滤。
- 跨平台核心回归检查、Windows DPAPI／损坏文件／WPF 构造检查、CI 便携 ZIP。

### 编译与测试

```powershell
cd windows
pwsh ./test.ps1
pwsh ./build.ps1 -Runtime win-x64
```

2026-11-03，提交 `bf814f3` 已通过本机 27 项核心检查和 WPF 交叉编译（零警告、零错误），并在 GitHub Actions Windows runner 通过核心检查、DPAPI 加密／损坏文件保护和 WPF 窗口构造检查，完成自包含 x64 ZIP 打包。[查看验证记录](https://github.com/flyingcow-niu/clipkeep/actions/runs/41610002290)。这不替代真实桌面的跨应用验收。

### 发布前剩余工作

1. **人工桌面验收**：剪贴板各格式、焦点恢复、跨应用粘贴、管理员窗口、快捷键冲突、文件失效、睡眠恢复；不能用窗口构造测试替代。
2. **功能对齐**：自动缩写与中英文标点匹配、输入法组字保护、手动短语编辑、自定义快捷键、登录启动。
3. **多屏与性能**：当前面板定位主屏；历史快照整包加密写入，需验证大容量下响应并按结果改为增量存储。
4. **分发与恢复**：Windows 签名、安装器、版本升级／回滚和可迁移备份；目前只有未签名便携包。
5. **ARM64**：允许编译目标，但尚无原生设备运行验收；不将 x64 CI 当成 ARM64 验证。

人工验收步骤见 [桌面验收清单](MANUAL_TESTS.md)。
